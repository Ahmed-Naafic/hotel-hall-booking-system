Confirmations and short flows that must not lose the page behind them.

```jsx
<Dialog eyebrow="Almost there" title="Confirm your stay" onClose={close}
  footer={<><Button variant="ghost" onClick={close}>Back</Button><Button>Reserve</Button></>}>
  Harbour Suite, Aug 12–15. $744 total.
</Dialog>
```

Positions absolutely inside the nearest positioned ancestor, so a screen mock can host it without portals.
