Primary action control for every Hotel Hall surface; uppercase, wide-tracked labels.

```jsx
<Button variant="primary" size="lg">Check availability</Button>
<Button variant="gold" iconLeft={<Icon name="sparkles" />}>Plan an event</Button>
<Button variant="secondary">Room details</Button>
```

Variants: `primary` (navy, default), `accent` (teal), `gold` (event/celebration CTAs only), `secondary` (outlined), `ghost`, `inverse` (white, for use on navy or photography). Sizes sm/md/lg. `loading` keeps the button width and pulses three dots. Labels are verb-first and 1–3 words — never "Submit".
